台鳳里透過 TNVR 行動及宣導正確觀念，打造人貓共好的友善生活圈 🪴

TNVR 是什麼？

四個步驟一次做完，才算完成一輪。順序不能跳。

  1. T

    捕捉

    Trap

    誘捕籠請向里辦公處或動保單位借用，捕捉後全程覆蓋布巾安撫。

  2. N

    絕育

    Neuter

    由合作獸醫院執行結紮手術，術後留院觀察，母貓再多休養幾天。

  3. V

    施打疫苗

    Vaccinate

    同時完成狂犬病疫苗與必要防疫處置，降低疾病在社區流通。

  4. R

    原地放回

    Return

    回到原本熟悉的巷弄，牠會守住地盤，外來未絕育的貓就進不來。

現行能有效控制流浪動物數量的方式，並可降低干擾事件及掌握區域流浪動物狀況 🐱
